# Fun4All 🎉

A modern, responsive, and engaging web project designed to deliver interactive experiences for everyone. Built with clean HTML5, CSS3, modern layout techniques, and responsive design standards.

---

## 🚀 Features

- **Responsive Design:** Seamlessly adapts across mobile, tablet, and desktop screens using modern CSS Grid and Flexbox.
- **Accessible (a11y):** Built following WCAG guidelines with semantic markup, proper contrast, and screen-reader-friendly structure.
- **Component-Driven Styling:** Clean, maintainable UI components using modern CSS/Sass patterns.
- **Lightweight & Fast:** Optimized assets and minimal overhead for smooth performance.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structuring (`<main>`, `<nav>`, `<fieldset>`, etc.)
- **CSS3 / Sass:** Flexible box layouts, responsive grids, and clean styling conventions
- **JavaScript:** Client-side interactivity and dynamic features
- **Bootstrap 5:** Utility classes and responsive grid foundation (optional/integrated)
